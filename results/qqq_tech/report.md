# QQQ + tech — every chart rule, puts and calls

Raw moves of the actual symbol (no SPY adjustment). 'Your-way move' = how far it moved in the trade's direction (puts: down, calls: up). Random = that symbol's average move over ALL days of the same period (2000-15 / 16-21 / 22-26). Edge = setup minus that. t clustered by month (overlapping trades counted once).

Data: QQQ from yahoo 1999, SPY from yahoo 1999, IWM from yahoo 2000, DIA from yahoo 1999, XLK from yahoo 1999, SMH from yahoo 2000, SOXX from yahoo 2001, IGV from yahoo 2001, XLC from yahoo 2018, XLY from yahoo 1999, FDN from yahoo 2006, ARKK from yahoo 2014, AAPL from yahoo 1999, MSFT from yahoo 1999, NVDA from yahoo 1999, AMZN from yahoo 1999, META from yahoo 2012, GOOGL from yahoo 2004, TSLA from yahoo 2010, AMD from yahoo 1999, AVGO from yahoo 2009, NFLX from yahoo 2002
