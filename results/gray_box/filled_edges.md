# Gray Box: filled box edges vs open boxes

75 names (data_ext, 5m bars), 2016-2026. Same rules and exits as the live bot v2 (half off at half a range). Result is in daily ranges per triggered trade (stock move, no option P&L).

## Answer

Average result per triggered trade: open boxes +0.002 (2016-21) and -0.001 (2022-26); filled edges +0.005 and +0.007. Filled edges did at least as well as open boxes in both halves. But every one of these is within 0.02 of a range of zero: after the stop and exits, NEITHER level type has an edge mechanically. Filled edges are no worse than open boxes, so using them as levels is fine; neither is a system by itself.
